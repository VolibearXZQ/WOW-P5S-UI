# P5S Showtime — 标准 1.000 / 紧凑 1.001

为 P5S 定制的英文与数字显示字体。成品位于上级目录 `P5S-Showtime-Regular.ttf`，系统字体族名称为 **P5S Showtime**。

现有标准版保持原文件；`P5S-Showtime-Compact.ttf` 更新至 **1.001**，字体族仍为 **P5S Showtime Compact**，不增加第三种版本。两版采用相同字形、粗细、高度和逐字倾斜。新版紧凑为 62 个英文字母与数字设置每侧 6/1000 em 基础留白，并对 3844 对组合按实际轮廓空隙重新调整字偶距，让倾斜字的外接范围可以相互嵌入。仅横向平移轮廓并更新字宽和字偶距，不压扁、缩放或重新旋转笔画。标点、空格及其他字符的轮廓、字宽，以及非目标组合的已有字偶距保持不变。

同字号下、HarfBuzz 实际启用字偶距的排版对比：

| 样例 | 比标准版缩短 | 比上一版紧凑再缩短 |
|---|---:|---:|
| 0123456789 | 11.94% | 5.65% |
| A–Z 连续排列 | 13.11% | 7.42% |
| a–z 连续排列 | 13.78% | 7.37% |
| HP / SP 单独标签 | 11.69% / 8.69% | 6.62% / 3.24% |
| 100 | 17.27% | 10.49% |
| Innovation in China | 12.69% | 5.55% |

光学校准以 1000 ppem 测量轮廓行包络，纵向增加 3 单位余量，目标轮廓间隙为 6 单位、单对最大收紧 180 单位。字体同时写入数值一致的 OpenType GPOS 和传统 kern 记录；排版引擎使用相应机制，不应叠加两次。独立 2000 ppem 检查测得所有目标组合的轮廓间隙仍为正，但这不保证小字号加描边时完全分离。客户端若忽略字偶距，仍保留基础紧凑字宽，无法呈现本次全部收紧效果。标准版 SHA256 保持 `0137bd2740f4d4dbfb74f4f16335963e48538b00fe20e745105a2ae322a12882`。

## 本版设计

- 基于用户提供的 `FugazOne-Regular.ttf`（内部版本 1.002），保留其粗壮、硬朗的轮廓风格。
- 重新设计 A–Z、a–z、0–9 共 62 个字符的倾斜和字距。先抵消 Fugaz One 的统一右斜（I 的竖干横向位移 126 / 高度 720），再逐字旋转。
- 参考用户提供的“微软雅黑粗体.ttf”实际英文与数字的视觉规律；不采用简单奇偶交替。角度表综合参考轮廓竖向边缘测量与视觉校准，属于光学校准值，并非原字体内存储的旋转参数。圆形、弧线、对角线较多的字符无法仅用一条竖干确定角度。
- `tilt-map.json` 是完整参数表，正数表示字顶向右，负数表示字顶向左。例如 0=-11°、1=+9°、4=+15°、8=-8°、H=-7°、P=-10°、b=+13°、m=-13°。
- 重新设置这 62 个字符的左右留白，底部沿用各字原有基线或下伸位置；保留原标点、字符映射、其他字符轮廓及原有字偶距。重建复合轮廓，避免未修改的重音字符意外继承已旋转的基本字母。
- 删除失效的原字形提示和数字签名，更新字体名称、版本、度量和校验和，使用系统栅格器绘制。

本版未加入中文字形；字符覆盖沿用原字体的 226 个 Unicode 映射、229 个字形。原始 Fugaz One 和参考字体均未覆盖、移动或修改，未从参考字体复制或合并任何字形。它不是微软雅黑字体的替代中文字体，也不把 Fugaz One 的硬朗笔画改成参考字体的圆润笔画。

## 构建与检查

需要 Python 和 fonttools；在本目录运行 `python build.py`。构建读取上级原始 Fugaz One 和本目录角度表，输出上级成品与本目录 `build-report.json`（包含来源、成品 SHA256 及逐字参数）。修改角度后可重建。构建不需要参考字体，也不会将参考字体内容写入输出。

紧凑版需要 fonttools、Pillow、numpy，单独运行 `python build_compact.py`，读取已制作好的标准版，仅输出 `P5S-Showtime-Compact.ttf` 和 `compact-build-report.json`；不会重写标准版或原始 Fugaz One。保留标准版原构建脚本、角度表与构建报告。构建报告包含基础字宽及应用字偶距后的字宽；其中百分比以标准版字宽相加为基线，上表则采用 HarfBuzz 对两版实际排版的结果，两种统计口径会有细微区别。

紧凑 1.001 检查通过：全部字体表解析、Windows 临时私有字体加载/卸载、226 个映射字符六种字号渲染、HarfBuzz 对 3844 对组合的 GPOS/传统 kern 独立路径验证（位置和总宽一致、未双重叠加）、禁用字偶距的回退检查。独立 2000 ppem 检查轮廓最小间隙为 4/1000 em，禁用字偶距时最小间隙为 12/1000 em。逐点比对确认所有 229 个字形无形状或纵向变化；其他字形和字宽、字符映射、许可、纵向度量和非目标组合字偶距保留。重复构建一致，标准版、六份原字体及全部 Lua/TOC 的哈希不变。

字体解析、全部字符渲染、62×62 字符组合间距、重复构建一致性和原文件哈希核对记录在本次任务中；这些检查不能替代魔兽世界正式服验证。

正式服仍待验证：客户端加载、实际是否应用字偶距、HP/SP 与数字在原字号/描边/旋转下的清晰度、连续数字宽度、切换与重载。紧凑版尤其需确认小字号和描边下相邻字符仍可区分；系统渲染及 HarfBuzz 检查不等同于游戏渲染。新增或替换字体资源必要时需完整重启客户端，避免缓存旧字体。两版数字均保留比例字宽，不是等宽数字，也未加入中文。
