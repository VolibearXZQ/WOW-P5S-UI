# P5S Bounce — 标准 / 紧凑版 1.000

成品：`../P5S-Bounce-Regular.ttf`；内部字体族：`P5S Bounce`。

紧凑版：`../P5S-Bounce-Compact.ttf`；内部字体族：`P5S Bounce Compact`。

基于 Chewy Regular 1.001 制作，保留圆润、手绘感的原始笔形。A–Z、a–z、0–9 共 62 个字符按逐字角度表旋转；沿用 P5S Showtime 从参考字体整理的左右倾斜节奏，不是把整行统一设为斜体。正角度表示顶部向右，负角度表示顶部向左。角度表为光学设计参数，并非参考字体内存储的精确旋转数据；Chewy 原生笔画的不规则形态保留。

Chewy 本身没有 Fugaz One 的统一右斜，所以标准版直接旋转，不做整体去斜。旋转后保留每字原来的最低点，标准版每侧留白限制为 25–49/1024 em，扩大字符步进容纳倾斜后的轮廓；受影响的原始负字偶距按至少 25 单位边界间隙限制。数字使用比例字宽。

其他字符的轮廓和基础字宽保持；先展开组合字再修改，避免重音字的基字自动变化。字体映射仍为原有 228 字符，不含中文；旧 hinting 已移除，实际小字号描边仍需客户端测试。

## 紧凑版

采用 P5S Showtime 紧凑 1.001 的同一间距方案，并按 Bounce 的 1024 UPM 换算：62 个英文字母/数字每侧留白 6 单位，逐对轮廓目标间隙 6 单位，纵向余量 3 单位，单对最大收紧 184 单位。调整 3844 个组合，同时提供一致的 GPOS 与传统 kern 字偶距表；原有非目标组合的字偶距保留。字形只作水平平移，形状、倾斜、粗细与纵向坐标完全不变。标准 TTF 不改写。

HarfBuzz 实际排版测量：数字行 `0123456789` 比标准版短 13.17%，A–Z 全字母行短 15.03%，a–z 全字母行短 15.80%；`HP` 短 12.61%，`SP` 短 10.19%。这是指定样本文字在读取字偶距时的结果，并非所有文本固定缩短同一比例。忽略字偶距的客户端仍会使用较窄的基础字宽。

紧凑版通过所有字体表解析、229 字形逐点形状核对、228 字符六种字号渲染、Windows 临时加载/卸载、3844 对 GPOS/传统 kern 独立排版及禁用字偶距回退检查；重复构建一致。独立 2048 ppem 测量最小轮廓间隙 2.5/1024 em，不代表小字号加粗描边一定分离，实际效果仍需游戏内验证。

## 复现与验证

需要 Python 与 `fonttools`；在本目录运行 `python build.py`。输入只有原始 Chewy TTF 和 `tilt-map.json`，不需要参考字体。版本校验拒绝意外的源文件；固定字体时间戳，输出摘要与逐字参数记录在 `build-report.json`。

紧凑版另需 `Pillow` 和 `numpy`，运行 `python build_compact.py`；输入为标准版 TTF，输出另存为 Compact。参数、源文件/输出摘要及样本文字宽度记录在 `compact-build-report.json`。两版共用本目录的 Apache 2.0 许可证与 NOTICE。

两版字体尚未加入 `/p5s` 的静态清单，单纯复制文件不会自动出现新菜单项。本次交付独立字体，正式服加载、HP/SP 与数字、字偶距支持、小字号描边、重启及切换表现均待接入后验证。
